# Overview

<h5>This is a chrome extension that will automatically skip ads on youtube. My goal was to design an ad blocker chrome extension that won't be flagged by youtube like other browser ad blockers do.
  This is done by the script looking for the skip ad button command in the youtube source code and applying a mouse click to essentially skip the ad. I was also curious in how chrome extensions worked so I decided to 
fix an issue that I've been experiencing and apply it to a new skill.  </h5>
